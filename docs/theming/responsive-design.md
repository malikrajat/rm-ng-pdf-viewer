# Responsive Design

Ensure the viewer component is responsive across all devices and screen sizes.

## Responsive Guidelines

1. **Flexible Height limits**: Use relative viewport units (e.g. `70vh`) for viewer height to ensure consistent layout rendering across device types.
2. **Container Adaptability**: The viewer wrapper width automatically expands to match parent container widths, adapting to screen resize events.
