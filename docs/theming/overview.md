# Theming Overview

Customize the styling and appearance of the PDF viewer.

## Theme Configuration

The custom theme configuration lets you style inputs, toolbars, buttons, state indicators, and accents.

Theme customization properties:
* **System Integration**: Synchronize themes with browser preferences automatically.
* **Granular Customization**: Style themes using design tokens or custom CSS variables.
