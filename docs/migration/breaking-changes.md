# Breaking Changes

A detailed list of breaking changes and how to update deprecated code.

## Breaking Changes List

* **Signals Migration**: Components consuming the viewer must bind parameters using standard templates.
* **dynamic imports**: Dynamic imports require standard browser execution environments, which may require guards in custom testing environments.
