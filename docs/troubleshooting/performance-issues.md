# Performance Issues

Diagnose rendering delays or memory consumption issues.

## Guidelines

* Ensure you call `revokeObjectURL()` on dynamically created URL streams to release memory assets.
* Enable lazy loading (`[lazy]="true"`) when displaying multiple viewer instances on a single page.
