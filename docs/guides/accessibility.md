# Accessibility

Our component is built with modern accessibility guidelines.

## Screen Reader Accessibility
The container frames injected by `@embedpdf/snippet` utilize standard semantic HTML trees, ensuring screen readers can announce page structures and document boundaries.

## Keyboard Hotkeys
The viewer supports keyboard shortcuts when focused:

* **Space / PageDown**: Scroll down a page
* **Shift + Space / PageUp**: Scroll up a page
* **Ctrl + (plus sign)**: Zoom in
* **Ctrl - (minus sign)**: Zoom out
* **Ctrl + 0**: Reset zoom scale
